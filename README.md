# Sweet Savory

Sweet Savory adalah website company profile untuk usaha rumah makan yang menyediakan berbagai pilihan makanan dan minuman dengan cita rasa manis dan gurih. Website ini dibuat sebagai proyek Sumatif Akhir Semester Pemrograman Web Dasar untuk memperkenalkan usaha kepada pelanggan melalui informasi profil, produk, harga, galeri, dan kontak yang mudah diakses.

---

# 1. Lembar Konsep Usaha

## Jenis Usaha

Rumah Makan

## Ciri Khas Usaha

Sweet Savory menawarkan berbagai menu makanan dan minuman dengan perpaduan rasa manis dan gurih yang disukai berbagai kalangan. Semua menu dibuat menggunakan bahan pilihan yang berkualitas dengan harga yang terjangkau.

# 3. Cara Menjalankan Website

1. Clone atau download repository dari GitHub.
2. Buka folder proyek menggunakan Visual Studio Code.
3. Jalankan file `index.html` menggunakan Live Server.
4. Website akan terbuka di browser dan siap digunakan.

# 6. Catatan Proses

## Kendala 1

Kelompok mengalami kesulitan dalam menghubungkan halaman satu dengan halaman lainnya karena beberapa path file tidak sesuai dengan struktur folder.

### Solusi

Kami memeriksa kembali lokasi file dan memperbaiki setiap tautan yang masih salah.

---

## Kendala 2

Tampilan website terlihat berbeda pada ukuran layar yang berbeda.

### Solusi

Kami menggunakan Flexbox dan Grid untuk membuat tata letak yang lebih rapi dan fleksibel.

---

## Kendala 3

Saat menggabungkan hasil kerja anggota kelompok, terjadi kebingungan karena beberapa file mengalami perubahan pada bagian yang sama.

### Solusi

Kami menggunakan branch dan pull request sehingga setiap anggota dapat mengerjakan tugasnya tanpa mengganggu pekerjaan anggota lain.
